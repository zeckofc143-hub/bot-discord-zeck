# Pocket Ants Farm Lab

Guia comunitário PT-BR de Pocket Ants, organizado para uso no celular.

## O que tem no site
- Farm de resina, honeydew, Body Parts, gems e pheromones
- Rota de progressão para early game
- Prioridade de Food Processing, Queen's Chamber e Resin Chamber
- Recomendações de criaturas com aviso quando a informação é opinião da comunidade
- Checklist diário salvo no navegador
- Busca e filtros por recurso
- Central de fontes oficiais, wiki e discussões de 2026

## Branch
Esta versão foi criada na branch `pocket-ants-guide` para manter o projeto isolado. O `main` do bot e os repositórios de tradução/manhwa não foram alterados.

## Observação
Guia comunitário não oficial. Pocket Ants pertence à Ariel Games. Como o jogo recebe atualizações, números e meta podem mudar.
